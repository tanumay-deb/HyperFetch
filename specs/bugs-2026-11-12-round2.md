# Open bugs, round 2 (2026-11-12)

Found reviewing the fixes for `bugs-2026-11-12.md` (all 24 pushed, each test
checked to fail before its fix). Same rules as that file: one bug, one commit,
a test that fails before the fix, the whole suite before pushing.

## Should

1. **Removing a paused torrent can freeze the window for up to 15 s.**
   Fix #21 (`abe5a51`) made `torrent.cleanup_artifacts` call `_let_go`
   (aria2 RPC, then waits up to 15 s) and `QueueManager.cancel_task` call
   `cleanup_artifacts`. The window's Remove (`gui2/app_shortcuts.py` ~101,
   `self.queue.remove_task(t)`) runs on the window's thread, so a busy aria2,
   or many torrents removed at once, freezes it - what 2.8.7 removed. Do the
   aria2 drop on a thread (the delete path already has one, b560657). Test:
   with a `_let_go` that blocks, `remove_task` from the window returns at once.

2. **The one-minute "no deno" cache defeats "install Deno, then Resume".**
   Fix #24 (`2e65fcd`): `yt_dl._deno` caches a miss for 60 s for every caller.
   The failure message itself records the miss, so a Resume within a minute of
   installing still finds no deno and fails again. Cache only for NameScout's
   look-up (`look_up` / `_choosing_opts` from it); a download's run and
   `explain` ask afresh. Test: a miss, then deno appears, then a download's
   `_choosing_opts` passes its path at once.

3. **Access violation in `tests/test_torrent_duplicates.py`** (open since
   2026-11-11, item 37 of the old list). Reproduces now, without the round-1
   fixes too: run `tests/` in name order up to and including
   `test_torrent_duplicates.py`; it dies in `test_a_web_link_that_is_gone_says_so`
   (line 183), inside the local QEventLoop in `gui2/app.py` `_fetch_torrent`
   (`loop.exec()`). Suspect: an earlier test's pending `deleteLater()` or timer
   delivered in that nested loop. CLAUDE.md's "OPEN:" paragraph has what was
   ruled out.

## Nice

4. **The status bar's theme button resets the accent of toggles and accent
   icons to purple.** `gui2/app_settings.py` `_toggle_theme` calls
   `apply_theme` (which sets `gui.theme.ACCENT` to the theme's default) and not
   `palette.set_accent` after it, as the two Settings paths do (fix #6).

5. **Move to… "moves" an unfinished download's partial onto itself when an
   unfinished-downloads folder is set** (fix #1, `gui2/app_actions.py`): with
   `utils.INCOMPLETE_DIR` set, `temp_path_for` returns the place the partial
   already is. Skip the move when that folder is set or the path is the same.

6. **A finished torrent with a very long name, moved, may be shortened** (fix
   #20: `utils.unique_path` now caps a name so the path stays under 232
   characters). A torrent's files must keep their names (CLAUDE.md "Torrents are
   not renamed"); its seeding re-add looks for them by name. Do not cap a
   torrent's top-level name, or refuse the move with a message.
