**New: more than one internet connection**
- A download can now use several internet connections at once, for
  example Wi-Fi and a phone connected by USB. It is off by default: in
  Settings, turn on "Show all settings", then under Network "Use more than
  one internet connection", and tick the connections to use. It never
  goes around a VPN.

**Downloads**
- A download takes the file name its server gives, as a browser does, and
  New Download shows that name before you start, even for links like
  "download.php?id=7".
- A paused download whose file was replaced on the server now stops with
  "The file changed on the server - Restart" instead of finishing as a mix
  of the old file and the new one.
- Downloads from sites that hand out the file from many mirrors, such as
  Fedora's, pause and resume without trouble.
- A signed-in link that redirects keeps your sign-in on its own site, and
  never sends it over plain http.
- A server that allows only a few connections is waited on instead of
  failing the download.

**Streams**
- A stream whose sound comes separately is saved with its sound, even when
  its playlist does not name its codecs.
- Picking another quality of a stream already in the list no longer says
  "Already added".
- A stream's sign-in cookies go only to its own site, not to video servers
  of other companies.

**Torrents**
- Torrents no longer write zeros into the parts of a file still to come.
- A removed torrent leaves no ".aria2" file behind, and a starting torrent
  shows its own name.
- After a crash, UPnP opens the port the torrent engine really listens on.

**Fixes**
- Downloads added from the web page no longer wait while New Download is
  open on the PC.
- Links on sites such as box.com or dropbox.com are no longer sent to
  yt-dlp as if they were videos.
- A per-host rule made only to use yt-dlp no longer forces 4 connections.
- An empty file, a file whose size the server cannot say, and a file sent
  as an attachment all download correctly.
- Plus smaller fixes to resuming, deleting and the web page.
